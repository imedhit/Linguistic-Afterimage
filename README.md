# Ec(ak)ou: Ghost Speech Cartography

Interactive speculative cartography of Bengaluru exploring human-only languages, clandestine signal trails, and spaces shielded from AI surveillance (2026–2050).

---

## 🚀 How to Publish to GitHub (Zero Commands Required)

This project has been pre-configured with **automated GitHub Actions** and **relative asset paths**. You do **not** need to install Node.js, run terminal commands, or execute `npm`.

### Step-by-Step:

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com) and click **New repository**.
   - Name your repository (e.g., `ghost-speech-cartography`).
   - Leave it public and click **Create repository**.

2. **Upload the Files**:
   - Extract your exported ZIP file.
   - Upload/push all files (including the `.github` folder) to your new GitHub repository.

3. **Turn On Automatic GitHub Pages (1 Click)**:
   - In your repository, click **Settings** (top tab).
   - In the left sidebar, click **Pages**.
   - Under **Build and deployment > Source**, select **GitHub Actions**.

4. **Done! 🎉**:
   - GitHub will automatically build and publish the site in the background.
   - Within 1–2 minutes, GitHub will display your live public URL right there on the Pages settings screen:
     `https://<your-username>.github.io/<repository-name>/`
   - You can share this link with anyone!

---

### Alternative: Pre-built `docs/` Folder
If you prefer not to use GitHub Actions:
- In **Settings > Pages**, set **Source** to **Deploy from a branch**.
- Select branch **main** (or **master**) and folder **/docs**.
- Click **Save**. The website goes live immediately!
